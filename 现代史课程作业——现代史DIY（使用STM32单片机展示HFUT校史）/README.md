# STM32实现HFUT校史记录展示装置

## 项目简介

本项目为合肥工业大学《近现代史纲要》课程DIY作业成果，主题是“STM32实现HFUT校史记录展示”。项目使用STM32F103C8T6作为主控，配合两块0.96寸OLED屏幕、8颗LED、按键和电源模块，将合肥工业大学校史节点做成可互动的电子展示装置。

本项目不是单片机课程作业，而是近现代史纲要课程中的红色文创DIY作品。单片机只是作品实现方式，核心展示对象是HFUT校史和校园文化。

## 核心功能

1. 上电后显示合肥工业大学校徽和校训界面。
2. 按下功能按键后，依次切换校史节点。
3. 双OLED分屏展示：一块屏幕显示图片，另一块屏幕显示年份和文字说明。
4. LED灯随展示进度逐步点亮，用灯光递增表现学校发展脉络。
5. 程序采用状态切换逻辑，便于增加新的校史图片、文字和灯光效果。

## 展示内容

当前程序内置的展示节点包括：

- 1945年：安徽省立蚌埠工业职业学校建校，即合工大前身。
- 1955年：学校提升办学层次，成功改为本科院校。
- 1956年至1958年：屯溪路校区修建，更名为合肥工业大学。
- 1960年：获评全国重点高校，跻身国家重点建设高校行列。
- 2001年：翡翠湖校区动工，开启多校区办学。
- 2005年：入选国家211工程。
- 2011年：宣城校区获批筹建。

主要硬件如下：

- STM32F103C8T6最小系统板 1块
- 0.96寸OLED显示屏 2块
- LED灯 8颗
- 轻触按键 1到2个
- 3V电源模块 1个

## 引脚连接说明

以当前源码为准，主要连接关系如下：

| 模块 | 单片机引脚 | 说明 |
| --- | --- | --- |
| LED灯组 | PA0到PA7 | 低电平点亮，按展示进度逐步点亮 |
| OLED屏幕1 | SCL=PB8, SDA=PB9 | 主要用于图片显示 |
| OLED屏幕2 | SCL=PA8, SDA=PA9 | 主要用于年份和文字说明 |
| 按键1 | PB1 | 预留按键，代码中已初始化 |
| 按键2 | PB11 | 主要切换按键，按一次进入下一展示状态 |
| 电源模块 | 3.3V/VBAT, GND | 严禁超压和反接 |

## 主要源码说明

### User/main.c

`main.c`是项目核心文件。程序先初始化OLED、LED和按键，然后进入无限循环。循环中读取按键值，如果PB11对应按键被按下，则更新`state`状态值，再调用`led_on(state)`控制LED点亮数量，并调用`show(state)`刷新双OLED显示内容。

### Hardware/LED.c

`led_init()`用于初始化GPIOA输出模式；`led_on(uint8_t weizhi)`用于控制PA7到PA0的LED点亮数量。由于LED采用低电平有效方式，程序通过写入GPIOA输出数据实现灯光递增效果。

### Hardware/Key.c

`Key_Init()`初始化PB1和PB11为上拉输入；`Key_GetNum()`通过读取输入电平判断按键是否按下，并加入延时消抖，避免误触发。

### Hardware/OLED.c 与 Hardware/OLED2.c

两个文件分别驱动两块OLED屏幕，均采用软件I2C方式。第一块OLED使用PB8/PB9，第二块OLED使用PA8/PA9，便于双屏独立刷新。

### Hardware/OLED_Data.c

该文件保存校徽、校史图片和字模数组。若需要增加新图片，应先将图片处理为适合OLED显示的尺寸，再进行取模，并把数组加入该文件中。

## 编译与烧录

1. 使用Keil uVision5打开`Project.uvprojx`。
2. 确认目标芯片为STM32F103C8T6。
3. 确认`User`、`Hardware`、`System`、`Library`、`Start`等文件已加入工程。
4. 编译工程，若无错误即可下载到单片机。
5. 上电后观察两块OLED和LED灯组是否正常工作。

## 使用方法

1. 检查电源正负极、OLED接线、LED接线和按键接线。
2. 接通电源，等待OLED显示初始校徽界面。
3. 按PB11对应按键，切换到下一校史展示节点。
4. 连续按键可依次浏览全部校史内容，LED灯会随进度逐步点亮。
5. 若出现黑屏、花屏或按键无响应，可先断电检查接线，再重新上电。
